## My Background and Skills

Completing my Computer Science degree has helped me develop a better understanding of how software is designed, developed, tested, and maintained. Throughout the program, I worked with different programming languages, databases, algorithms, and development tools. These experiences helped me move beyond simply writing code to understanding why certain approaches work better than others and how software decisions affect the people who use it. Developing my capstone ePortfolio also gave me an opportunity to revisit previous projects, identify areas for improvement, and demonstrate how I have grown as a developer.

My strongest interests are in software development, backend programming, databases, and building practical applications. I have experience working with Python, Java, JavaScript, TypeScript, Django, Flask, Vue, and SQL and NoSQL databases. Coursework involving data structures, software development, database management, and web application development helped me understand how these technologies fit together. I have also worked with tools such as Git, Docker, and pytest, which helped me become more familiar with development workflows, testing, and maintaining projects. I enjoy working through technical problems and finding solutions that are practical without making the code more complicated than necessary.

One important skill I developed throughout the program is understanding data structures and algorithms and knowing when to use them. Learning about searching, sorting, and algorithm efficiency helped me recognize that a solution should not only produce the correct result but should also use resources effectively. My coursework helped me understand how to evaluate different approaches based on the problem being solved. This has influenced how I approach development by encouraging me to consider performance, maintainability, and trade-offs instead of focusing only on getting something to work.

Software engineering and database development have also been important parts of my education. Working with object-oriented programming, APIs, database queries, and application architecture helped me understand how individual components work together to form a complete system. I learned the importance of separating responsibilities, validating input, handling errors, and testing different scenarios. I also gained experience working with relational databases and MongoDB, which helped me understand different approaches to storing and retrieving information. These skills are relevant to the type of software development work I want to pursue after graduation.

Security is another area I have come to appreciate more as I have progressed through the program. An application can function correctly and still have serious weaknesses if it does not protect user information or restrict access appropriately. Authentication, permissions, input validation, and secure configuration are all important considerations when building software. My capstone work gave me an opportunity to apply these ideas more directly, but I also recognize that security is an area where I need to continue learning as technologies and threats change.

My professional experience has also influenced the way I approach technical problems and communicate with others. Working in a management role required me to coordinate with employees, communicate with managers and suppliers, organize responsibilities, and resolve operational issues. I also gained practical experience supporting technology used in business operations, including configuring networks and cameras and managing systems used for orders and payments. These responsibilities taught me that a technical solution needs to address the actual needs of the people using it. Communication is important because technical decisions often affect people who do not have a technical background. I have learned to explain problems in practical terms, consider different priorities, and focus on solutions that support the larger goal.

Although my coursework included substantial independent programming and development work, I understand that professional software development also depends on collaboration. Developers need to share information, document their decisions, listen to feedback, and make changes based on requirements from stakeholders and other team members. My work experience has helped me develop communication and coordination skills that I can bring to a technical team. As I begin my career in software development, I want to continue improving these skills while gaining more experience working with other developers in a professional environment.

My goal is to build a career in software development, with particular interest in backend systems, APIs, databases, and application design. I want to continue strengthening my technical skills while learning from real-world projects and experienced developers. Completing this degree has given me a stronger foundation, but I see it as the beginning of my professional development rather than the end of my learning. I want to build software that solves real problems, is maintainable, and provides value to the people who depend on it.

## My ePortfolio

The artifacts in this ePortfolio demonstrate different aspects of my development as a computer science student. Together, they show my ability to work with existing code, improve software functionality, apply algorithms, and develop applications that manage data. I selected these projects because they allowed me to build on work from earlier courses and demonstrate how I could apply what I learned to improve an existing solution.

The first artifact is the CS-320 Contact Service, which demonstrates my software design and engineering skills. I recreated the original Java application in Python while preserving its core functionality. This work involved implementing the contact model, validating input, handling errors, and writing automated tests. Recreating the application also required me to consider how the original design could be translated into another language while keeping the code organized and maintainable.

The second artifact is the CS-340 Animal Shelter Dashboard, which demonstrates my knowledge of algorithms and data structures. The original application allowed users to filter animal shelter records and view the results through a dashboard. I enhanced the search functionality by implementing binary search and sorted indexes, along with caching to avoid repeatedly preparing the same data. I also added automated tests to check the search logic and different edge cases. This project helped me apply algorithmic concepts to an existing application and evaluate the trade-offs involved in improving search performance.

The third artifact is the Contact Service database enhancement. Building on the Python version, I added MongoDB persistence so that contacts could remain available after the application closed. I also implemented user authentication, role-based permissions, improved validation, and database error handling. Automated tests were added to verify the new functionality, and the enhanced project finished with 75 passing tests. This artifact demonstrates how database integration, software engineering, and security considerations work together in a complete application.

Together, these projects represent my progress in three important areas of computer science: software engineering, algorithms and data structures, and database development. They also show that I can do more than create an initial implementation. I can review existing code, identify weaknesses, make targeted improvements, test the results, and explain the reasoning behind my decisions. Through this ePortfolio, I want to demonstrate the technical foundation I have developed during my degree and my readiness to continue growing as a software developer.
